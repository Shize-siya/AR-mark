---

## 交付清单

### 1. 完整源码
- Unity 项目源码
- React 管理端源码
- Go 后端源码

### 2. README.md
简短的 README.md，说明：
- 使用的版本
- 三个部分如何启动
- Unity 真机如何配置 Go 后端地址
- 已完成、未完成和已知问题

### 3. AI_LOG.md
按实际顺序保存所有主动发给 AI 的问题或指令，包括追问和纠错。

**每条记录格式：**
```markdown
## P-001
- 目标：解决什么问题
### Prompt 原文
> 实际发送给 AI 的问题或指令
### 结果
- 采用 / 修改后采用 / 未采用
- 简要说明如何验证
```

**AI_LOG 要求：**
- 必须保留 Prompt 原文，不能只写总结
- 不需要记录 IDE 的逐字自动补全
- 至少记录一次检查、修改或放弃 AI 结果的过程
- 需要能够解释最终提交的核心代码
- 不得提交 API Key、Token、账号、个人隐私或其他敏感信息
- 如需脱敏，使用类似 `[REDACTED: API token]` 的占位内容

### 4. 演示视频（两段）
**两段 3～5 分钟演示视频（手机和电脑），至少展示：**
- 真机识别平面并放置标记
- 手机提交问题
- React 刷新后看到该问题
- React 修改状态
- Go 重启后数据仍然存在

## 交付方式
完成后，通过以下任一种方式分享全部交付内容：
- GitHub 仓库
- Gitee 仓库

- 不强制部署到公网
