## 项目名称
Unity AR 园区巡检标记系统（实操题原型）

## 项目背景
园区巡检人员发现墙面破损、设备异常或安全隐患时，希望用手机在现场放置一个 AR 标记并上报问题。管理人员随后在电脑网页中查看这些问题并更新处理状态。

## 核心流程
```
Unity AR 放置标记并上报 → Go 后端保存 → React 页面查看问题 → React 修改处理状态
```

## 系统组成
- **Unity AR 移动端**：检测平面、放置标记、上报问题
- **Go 后端**：提供 API 并持久化数据
- **React 管理端**：查看问题、修改状态

## 设计原则
本题以完成基础功能为主，不要求复杂架构和精美界面。
